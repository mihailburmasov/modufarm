- **Pages:** источник публикации — GitHub Actions (переключено 14.10.2026). Сборка — `.github/workflows/pages.yml`; для пуша изменений этого файла токену нужно право `workflow`.
- **Пробные правки в админке** попадают в `data/` и уйдут на сайт с коммитом. Перед коммитом смотреть `git diff data/` (14.10.2026 так чуть не ушла опечатка «Республика крым» — откатили).

- **Репозиторий публичный.** Почту, токен Telegram-бота не коммитить — заполнять на сервере.
- **В истории git (первый коммит 0eb7233) в HANDOFF были ФИО экспертов-аудиторов** из сертификата ИСО. В текущей версии их нет, но история хранит. Переписать историю (force-push) — только по решению пользователя, пока не делали.
- **Заявки и пароли** — в `storage/` рядом с корнем сайта, а не в нём: снаружи не скачиваются, в git не попадают.
- **Отправка письма не проверена**: локально нет почтового сервера. Заявка пишется в журнал до отправки и видна в админке (проверено, вместе с UTM).
