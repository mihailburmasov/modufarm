# ModuFarm — сайт разработчика сельхозроботов (ООО «Ключ «Гремячий», Крым)

Одностраничный сайт: сельхозроботы под агротехнические задачи и проектирование фруктовых садов. Цель — заявка «Обсудить задачу».
Статика (HTML/CSS/JS) + обработчик заявок `send.php` (PHP 7.4+).

## Структура

| Файл | Что это |
|---|---|
| `index.html` | Главная: первый экран, 6 направлений, «Робот под культуру», проекты садов, «Кому полезно», этапы, документы, форма |
| `spasibo.html` | Страница после отправки заявки |
| `politika.html`, `soglasie.html` | Политика и согласие (152-ФЗ), оператор — ООО «Ключ «Гремячий» |
| `css/style.css`, `js/main.js` | Стили и скрипты |
| `send.php` + `config.php` | Приём заявок: почта, Telegram (необязательно), журнал `data/leads-*.csv` |
| `docs/` | PDF свидетельств Роспатента (6 шт.) и сертификата ИСО (только стр. 1–2) |
| `img/docs/` | Превью документов (WebP, отрендерены из PDF) |
| `fonts/` | Onest — одно семейство для заголовков и текста, самохостинг |
| `img/og.jpg`, `img/apple-touch-icon.png`, `favicon.svg`, `img/logo-light.svg` | Превью для соцсетей и иконки |

Все иллюстрации (робот в саду, схема сада) нарисованы в SVG прямо в `index.html`. Фото со стоков не используются.

## Перед запуском

1. **Почта для заявок** — `config.php` → `to_email`; `from_email` — ящик на домене сайта.
2. **Домен** — заменить `DOMAIN` в `index.html` (canonical, OG, JSON-LD), `robots.txt`, `sitemap.xml`, `config.php`; `[адрес сайта]` в `politika.html`, `soglasie.html`.
3. **E-mail оператора** — жёлтые поля `[e-mail]` в `politika.html`, `soglasie.html`.
4. **E-mail на сайте** — закомментированный блок `lead__contacts` в `index.html` (поиск `ЗАПОЛНИТЬ`). Телефон уже стоит.
5. **Яндекс Метрика** (по желанию) — `METRIKA_ID` в `js/main.js`. После включения обновить текст cookie-баннера и раздел 6 политики (сейчас там честно написано, что аналитики нет).
6. **Подтвердить у заказчика** (комментарии `ПОДТВЕРДИТЬ` в `index.html`): состав робота, состав проекта сада, этапы работы.

## Хостинг

- Обычный хостинг с PHP (Beget, Timeweb и т.п.): залить всё как есть, `mail()` должен работать.
- GitHub Pages / Object Storage PHP не выполняют — форма там не отправится (нужна Cloud Function, её адрес — в `FORM_ENDPOINT` в `js/main.js`).
